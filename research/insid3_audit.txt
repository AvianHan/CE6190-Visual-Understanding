MECHANISM
One reference RGB + binary mask, one target/query RGB; output one binary semantic concept mask. Semantic = all instances of class; part = same object part; personalized = same physical instance. Single frozen DINOv3-L/16 (paper 304M); no gradient training or learned segmentation decoder or SAM. Distinguish pretrained backbone's self-supervision from no information: a reference mask is provided, and hyperparameters were selected on COCO training data using 3-fold CV (supp B). Do not claim zero supervision of every kind.
Original DINOv3 target features -> cosine average-linkage agglomerative clustering, granularity tau=.6. Debiased reference/query features -> each query patch selects nearest reference patch; keep matches landing in reference foreground. Average masked reference features => prototype; choose most similar candidate-cluster prototype => seed. Combine cross-image similarity with intra-query seed similarity; merge qualifying clusters; bilinear upsample + CRF in paper. Positional projection estimated via SVD of low-content input features; paper Gaussian noise, current code zeros. Original features deliberately retained for within-image grouping, debiased only for cross-image matching. Gram anchoring causing positional bias is authors' hypothesis, not causally proven.

DATASETS AND CURRENT CODE PROTOCOL
All class names/counts below need annotation-version checksum once actual data acquired. Original dataset counts and evaluated foreground taxonomy are not interchangeable.
COCO20i: COCO2014 images/preprocessed semantic masks + Matcher splits. 4 interleaved class folds; 20 classes/fold; 1000 sampled episodes/fold. split='val' refers supplied episode metadata. Underlying names may point to train2014 and val2014; do not label as merely COCO official val images. Query+refs class-matched, query != ref. 5shot refs can repeat.
LVIS92i: COCO2017 + lvis_val.pkl, ten folds from eligible categories (>shot images); paper920 categories. 2300 episodes/fold; cyclic class schedule, sampled image. Query/ref masks union all instances of target class. fold=-1 currently does NOT mean all classes: repeats fold0-like index slicing. Avoid it.
PASCAL-Part: VOC2010 + preprocessed part JSON. Paper56 parts/15 object classes. Four groups animals/indoor/person/vehicles; query AND ref from part val lists. Uses object GT box crops by default; image IDs must be distinct. Excludes aeroplane+TAIL. Episode count min(metadata_length,2500). This is object-cropped part task; full-image comparison is a separate protocol.
PACO-Part: COCO2017 + train/val part pickles. Metadata taxonomy nclass448, filtered evaluated303 per paper; four folds defined on train categories then eligible val categories. 2500 episodes/fold. GT object box crops default. Query/reference selected object instance and part; 5shot refs can repeat. fold=-1 NOT all classes.
ISIC2018: official Task1 training images/masks, reorganized by DR-Adapter class_id.csv into three category directories 1/2/3; docs call these folds but code treats as three classes. 2594 image/mask pairs, directory sizes208/1867/519; 600 episodes cyclic categories. Not official challenge held-out test split.
Chest X-Ray/Lung: preprocessed Kaggle aggregate, docs800images704masks. Code samples available masks (600episodes) with one pooled lung foreground class, not diagnosis; no explicit patient split in loader. Need source/patient identity controls for research extension.
SUIM: merged dataset1635images/masks; dataset8 labels incl background, code evaluates7 foreground categories FV/HD/PF/RI/RO/SR/WR. num_episodes=sum(nonempty class-mask files), not unique image count. Cyclic classes; queries random with replacement. No explicit original official train/test split in merged loader.
iSAID5i: 15classes3contiguous folds, preprocessed val patches6363images+semantic maps. Query image/class pairs from fold text; reference sampled same fold and class, query distinct; label255 ignored. Need parent-image constraints to prevent nearby tiles mixing query/reference in robustness extension.
PerMIS: derives from BURST/TAO via PDM/PerMIRS generation. Docs216 folders×3 frames. Code first frame ref and frames1&2 queries =>432 episodes if all folders present. Same physical object; no video propagation in INSID3. Loader actually expects masks.npz.npy (doc says masks.npz). os.listdir unsorted. All class_ids=[0] => global foreground IoU pooled across sequence episodes in current shared evaluator. --shots ignored in actual ref count. Distinct from semantic all-class evaluation.
SPair71k: auxiliary keypoint semantic correspondence only; PCK, not segmentation mIoU, don't inflate segmentation dataset count.

OFFICIAL METRIC
utils/metrics.py AverageMeter sums foreground intersection and union over all episodes of each class, computes each class IoU=sumI/max(sumU,1), then macro-averages classes. This differs from average episode IoU. Missing/zero-union class =>0. PerMIS labels all episodes class0 so this becomes globally pooled foreground IoU. fb_iou also exists but main evaluation returns only mIoU. Eval resizes GT via nearest to prediction size; ignores supplied ignore mask after nearest resizing. iSAID supplies ignore; other loaders do not generally supply it.

Main Eq14 unconditionally adds seed; supplementary absent-target adaptation permits thresholded seed. Document as implementation details, do not silently alter.
