Semantic category and part protocols available; 1/5-shot commands. https://github.com/aim-uofa/Matcher ; https://github.com/aim-uofa/Matcher/blob/main/GETTING_STARTED.md ; https://github.com/aim-uofa/Matcher/blob/main/datasets/README.md

DATASET POOL / PROTOCOL NOTES
The anchor auditors own exact anchor split audit. These are independent verified source paths and extension notes.
Natural category:
- COCO-20i: COCO2014 train/val images + prepared semantic masks/splits, 80 classes/4 folds. Matcher setup verified. Need freeze same episodes not just seed.
- LVIS-92i: Matcher-derived 920-class /10-fold benchmark using COCO2017 images and lvis_train/val.pkl. Not identical to full official LVIS instance AP benchmark.
- FSS-1000: original 1000-category binary-mask dataset official HKUSTCV repo; Matcher includes train/val/test class list files. Exact downloaded split list must be frozen. https://github.com/HKUSTCV/FSS-1000
- PASCAL-5i: VOC2012 plus SDS extended masks, four class folds; DC-SAM repo provides protocol preparation but training-dependent baselines need fold-specific checkpoints. https://github.com/zaplm/DC-SAM
Parts:
- PASCAL-Part: Matcher-prepared part masks on VOC2010. FoRIS/INSID3-type setup reports56 parts across15 categories, four folds. Must use prepared category mapping rather than raw full annotation definitions.
- PACO-Part: Matcher-prepared part subset on COCO2017,303 parts across75 categories, four folds; not full PACO attributes benchmark. Reuse image files with LVIS but don't claim independent image domains.
Cross-domain category:
- ISIC2018: lesion masks; official benchmark adapters regroup challenge training images by diagnostic classes; FoRIS docs report2594 pairs/3 groups of208,1867,519. Must not equate those folders with untouched official train/val/test. Validate patient leakage when redesigning support/query.
- Chest X-ray: lung masks; distribution referred via PATNet/INSID3 has800 images but704 masks. Evaluate valid mask intersection; declare source collection(s). Do not call disease segmentation.
- SUIM: official source1525 train/validation +110 test with8 labels including background/waterbody. Anchor-style merged release1635 images differs from untouched official held-out110. Must label merged episodic protocol vs official-split extension. https://github.com/IRVLab/SUIM
- iSAID-5i: aerial15 classes/3 folds; preprocessed val patch distribution used in FoRIS docs has6363 patches. Group by source scene if adding own splits, avoid adjacent crops crossing support/query holdout accidentally.
- DeepGlobe LAND COVER: PATNet established CD-FSS extension; keep preprocessing/land-cover label map exact. https://github.com/slei109/PATNet
Personalized:
- PerSeg: original PerSAM release links; preserve identity-specific references and evaluation behavior. https://github.com/ZrrSkywalker/Personalize-SAM
- PerMIS/PerMIRS: FoRIS inherited data docs refer Where's Waldo/PDM from BURST test,216 folders each3 frames and masks.npz. Useful same-instance with distractors; exact anchor name/mapping to be confirmed by INSID3 auditor. https://github.com/dvirsamuel/PDM
Stress-test extensions (not protocol-ready yet):
- Fundus retinal vessels from FoRIS AppendixF; exact underlying release and splits unresolved; do not advertise generic Fundus as a finished reproducible dataset.
- DeepGlobe ROAD EXTRACTION from FoRIS AppendixF is different task/labels from PATNet land-cover. Separate task IDs, not casually two independent domain datasets.
- Further candidates can add Kvasir-SEG/CVC-ClinicDB/polyp datasets, MoNuSeg/nuclei, Oxford-IIIT Pet, ADE20K, Cityscapes, LoveDA etc only after primary annotation/split/adaptation audit. No counts or readiness asserted here.

COMMON FAILURE/FAIRNESS OPPORTUNITIES (proposed not results)
- Training-free downstream != no mask supervision in foundation pretraining. Stratify supervision history and target-time updates.
- Same-image resolution and same-backbone controlled comparisons are ablations; paper-default method comparison also needed.
- Resizing ground truth to model output (FoRIS example) can distort small-object/boundary comparisons; production evaluator should restore predictions to original GT grid with fixed declared interpolation and ignore handling.
- Independent support selection manifests; same query/reference pairs; separate support-selection variance from model stochastic variance.
- Category union masks, identity masks and part-category masks require separate leaderboards.
- Sample-level latency warm/cold, cache policies, end-to-end vs model-only; no GT in prediction callable.
- No baseline tables spliced across papers as own results. REBASE/FoRIS published numbers only metadata, not experimental output.
