共同任务：reference 决定“分什么”

(reference image, reference mask, query image) → predicted query mask。主协议不把 ground-truth 类名或 query mask 交给 model。举例：reference 圈住一只狗；semantic 要找 query 中所有同类狗；personalized 要找同一只狗；part 若圈住狗耳朵，则目标是对应部件。三种目标分别建立结果表。

公平评测协议 v0.1（计划，待数据验证）

规则具体落实
两条结果线official reproduction 保存作者设置与 evaluator；harmonized comparison 使用统一 episodes、原始 GT grid 和同一聚合；两条结果不混表。
模型输入只给 reference images/masks 与 query image；不给人工类名、query GT、oracle boxes。原文 object-cropped part 另列协议并承认给定定位。文本 oracle 如做，只作标注清楚的诊断。
固定 samples预生成显式 episode manifest；记录 dataset version、split、class/identity、query/reference IDs、哈希、mask semantics、ignore label；与 method、rank、worker、GPU 数无关。
Reference / shots共同协议用 distinct references；跨方法完全一致；1/5-shot 使用共同 eligible class set 和嵌套 reference 设计（若可行）。作者重复采样协议保留为独立复现结果。
标注与分辨率保留原始 GT/ignore；预测逆变换回原始 grid；概率图 bilinear 后阈值、离散标签 nearest，具体顺序写入配置。主比较保留各方法合理原生输入尺寸；同分辨率为附加受控实验。
指标同时保留每 episode TP/FP/FN/TN；报告 class-pooled foreground mIoU、class-mean episode IoU 及 mean episode IoU，明确主要指标。part 与 personalized 采用各自协议，不跨任务平均。
空目标主任务通常 query 含目标；absent-concept 为独立 stress test，需完整标注确认真缺席；空空 IoU 策略写清；同时报告 present accuracy，避免永远输出空 mask 的伪稳定。
稳定性固定 query，换 reference；先计算每 query 的 IoU 分布，再按预定义规则汇总 Std、CV、lower quantile、failure rate。mean≈0 时 CV 不稳定，标记 undefined；不能只报告低 Std。
随机性与推断reference selection variance 与 MLLM sampling variance 分开；记录生成参数与实际 responses；paired comparisons；以 query/scene/patient 为 bootstrap cluster，避免把 repeated references 当独立 query。
数据与监督暴露记录 backbone、pretraining supervision、target-time updates；SAM3 文档有 partial LVIS training，不能将 LVIS 简称完全 unseen。无额外训练不等于完全无监督或没有 benchmark exposure。
预算与日志先测量真实资源，再选择 batch / workers / concurrency；GPU OOM、失败、超时全部记入结果状态；子集选择在看结果前固定。
超参数保留论文默认配置；新增调参用独立 validation；不可根据 test 最佳结果选参数。搜索预算、模型大小、CRF 与 resolution 单独命名 variants。

CG-ICS 成本不能只看 segmentation 进程

源码会缓存图像 embeddings。一次高层 infer() 可能触发多个 prompt head forwards，因此“模型调用次数”要拆分定义。对 m-shot，build_state 编码 m 个 reference、1 个 query 和 m 个拼接图；candidate scoring、reranking、visual boxes、最终预测都分别计数。

测量项记录方式
时间model loading / SVD 或 server startup；reference preparation；query inference；postprocess；完整 end-to-end；warmup 与 cold/warm cache 分开；CUDA 测量显式同步。
GPU memorySAM3 进程 allocated/reserved peaks；MLLM server 各设备 memory；CPU peak RAM；scope 和并发数。不同设备各自峰值之和不是瞬时总峰值。
调用DINO encoder、SAM image encoder、SAM prompt head、MLLM API requests、实际 candidate evaluations、rerank、restarts、fallbacks。
MLLMmodel / weights / dtype / tensor parallel / sampling config；input/output tokens；request latency；错误与 retries；实际 concepts 和 tree。
缓存缓存 key、命中率、reference 是否跨 query 重用；禁止跨方法只给一方缓存优势；检索和搜索耗时完整入账。

CG-ICS 官方使用本地 vLLM 的 OpenAI-compatible API，并非必须使用收费远程服务。作者的双 3090 server 配置不是已证明的最低硬件门槛。实际显存、吞吐和可用并发只能试跑后确定。
