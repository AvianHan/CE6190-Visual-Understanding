## Report-ready method wording

**INSID3.** INSID3 performs in-context segmentation using a frozen DINOv3 encoder, without fitting a task-specific segmentation decoder. Its implementation preserves two feature representations. Original normalized query features support cosine-distance, average-linkage agglomerative clustering and within-query similarity. Positionally debiased reference and query features support correspondence and reference-conditioned selection. The debiasing projection removes the leading SVD directions of features from a low-content image, then renormalizes the features. A foreground prototype is obtained from masked reference features. Forward similarity and backward nearest-neighbour matching localize query candidates; the reference prototype selects a seed among candidate clusters. The final cluster score combines cross-image alignment, similarity to the seed in the original feature space, and the fraction of each cluster supported by candidate localization. Thresholding these scores yields the predicted mask. [Paper: `insid3`; exact mechanics: pinned `models/insid3.py` and `utils/clustering.py`.]

**CG-ICS.** CG-ICS combines a frozen SAM 3 segmenter with a multimodal language model. Qwen3-VL-4B-Instruct proposes textual concepts from the reference image and a highlighted crop of its annotated foreground. Each concept is scored using reference fidelity, measured as IoU with the supplied reference mask, and SAM 3's query-presence score. Their product guides concept search, including expansion, pruning, restarts and final reranking in the pinned implementation. A parallel visual route horizontally concatenates the reference and query. Reference-mask components provide spatial prompts on the concatenated image; predicted query-side masks yield box prompts for the query. Final segmentation combines the selected text with these visual prompts. Query ground truth is used only by the external evaluator. [Paper: `cgics`; model citations: `sam3,qwen3vl`; exact mechanics: pinned `model/tree_search.py`, `model/sam3.py`, `model/mllm.py`, and project adapter.]

**Why the comparison is of complete systems.** INSID3's grouping and matching algorithm, DINOv3 representation, input processing and refinement differ from CG-ICS's SAM 3, language model, search and visual prompting. Consequently, a difference between their full-system scores does not isolate the backbone. The explicit trunk-by-processing experiment and within-system component ablations address narrower questions. Both systems avoid task-specific parameter updates here; this does not imply identical pretraining data or supervision. Disjointness from every pretrained component's data is not established by this project's manifests.

**Correction to the earlier audit:** The SAM 3 README's “partially trained on LVIS” asterisk belongs to the **OWLv2 comparator**, not the SAM 3 row. Its full HTML table and SAM 3 paper section F.1 explicitly identify that OWLv2 checkpoint. Do not claim partial LVIS training for SAM 3 on the basis of that footnote. The earlier note inherited a misreading and is superseded by this correction.

## Implementation details that must remain visible

1. **Positional basis.** The INSID3 paper describes Gaussian noise. Commit `0c165a10cf52ab91f335883d06260de86854adbe` actually constructs an all-zero RGB image and ImageNet-normalizes it before extracting and centring its features for SVD. Report the implementation used; do not describe the executed basis as sampled Gaussian noise.
2. **Original versus debiased features.** Clustering and seed-to-cluster self-similarity use original features. Cross-image matching and prototypes use debiased features. Saying all features are debiased before clustering is incorrect.
3. **Aggregation.** For cluster k, the code computes the mean debiased foreground similarity times the original-space seed similarity times candidate-coverage weight. The seed coverage weight is set to one, but the seed still passes through the merge threshold; it is not unconditionally included.
4. **Resolution and refinement.** Current main INSID3 configuration uses 1024-pixel working size, SVD rank 500, clustering similarity threshold 0.6, merge threshold 0.2 and bilinear restoration; CRF is not enabled in that configuration. Current CG-ICS configuration uses 512-pixel working images followed by SAM 3's internal 1008-pixel preprocessing and nearest restoration. Check frozen bindings before claiming these values for results. Both adapters evaluate at original query resolution, a documented change from portions of the authors' evaluation code.
5. **CG-ICS scores.** Query presence is a model score, not query-mask IoU. The supplied reference mask can be used to evaluate a candidate on the reference. In the upstream score function, alpha=beta=0 gives random scores; it is not a deterministic unscored baseline.
6. **CG-ICS search.** Reuse of the pinned search does not justify describing it as a mathematically complete breadth-first expansion: its loop can stop on reaching the configured maximum depth while other frontier nodes remain. One-shot search still performs final reranking. A very low final score can produce the literal prompt `visual`.
7. **Visual prompts.** In the pinned wrapper, masks are converted into boxes. A “joint final inference” may run the text head and additional prompt-head executions as boxes are accumulated. Report actual encoder, head, SAM-wrapper and MLLM request counters separately.
8. **Cost boundaries.** Adapter time includes the extra probes and fallback search. Model initialization is separate. The external language-model server's memory is not included in the segmentation-process GPU peak; MLLM request time includes waiting, transport and generation. Shared-server throughput is not isolated per-model latency.
9. **Dataset naming.** Cite `coco,lvis` for the source datasets, and explain that COCO-20^i and LVIS-92^i are the project's frozen episodic segmentation protocol. LVIS-92^i is not the full LVIS instance-AP benchmark. One common manifest plus original-image ground truth does not reproduce every author sampling/aggregation choice.
10. **Reference stability.** Repeated references for the same query share a query-level unit. Average or resample within query appropriately; do not count every reference pairing as an independent query.

## Second-batch method status and wording

Proposal A is a project hypothesis, not an established result: compare text-only and visual-only predicted masks from the initial concept and shared visual transfer. If both are nonempty and their IoU reaches the predeclared threshold, retain the initial concept; otherwise invoke the original search before final joint segmentation. Threshold 0.7 is primary, with 0.5/0.9 sensitivity checks. Random-search controls and an original-score gate test whether any gain reflects the proposed cue rather than spending less search. Prediction agreement can be wrong because both predictions may share systematic SAM 3 errors. The second-batch result placeholders must remain empty until real outputs are audited.

For the fixed-pool ablation, generate one pool, retain all scores, and compare combined, reference-only and query-only rankings with identical final visual prompts. Hold the very-low-score fallback common to all rules using the maximum combined score. The bundled execution shares candidate generation and scoring; its total runtime is not three independent algorithm latencies.

## Optional related-work sentence

SAM introduced general promptable segmentation (`sam`); PerSAM subsequently adapted a reference image and mask to personalized segmentation without fitting model parameters, while PerSAM-F fitted two scale-combination parameters (`persam`). These works motivate reference-conditioned segmentation but do not make personalized-instance evaluation interchangeable with class-level COCO/LVIS episodes.

## Transfer datasets: exact P3 provenance and citation placement

**SUIM** expands to *Semantic Segmentation of Underwater Imagery*. Cite the dataset paper `suim` when first introducing the underwater transfer scope. The original dataset distinguishes 1,525 training/validation images and 110 test images. The project's author-prepared **merged** source combines those pools (1,635 source images); usable image/mask pairs are subject to the recorded input validation and exclusions. The evaluation uses seven foreground categories, excluding background/waterbody. Its class codes are `FV`, `HD`, `PF`, `RI`, `RO`, `SR`, and `WR`. This is not an evaluation on the original 110-image SUIM test split alone. The pinned INSID3 data instructions explicitly obtain the `suim-merged` preparation following ABCDFSS; the project preserves that layout and records its source. Suggested wording: “The transfer scopes use the author-prepared merged SUIM underwater dataset~\\cite{suim} and the reorganized public ISIC 2018 lesion-segmentation training data~\\cite{isic}.”

**ISIC is specifically ISIC 2018 Task 1.** Both pinned INSID3 instructions and the second-batch source-preparation code use `ISIC2018_Task1-2_Training_Input` together with `ISIC2018_Task1_Training_GroundTruth`. These are 2,594 dermoscopic images and their binary primary-lesion masks; the mask task is lesion boundary segmentation, not diagnosis classification. The shared Task1/2 image archive name does not make this an attribute-segmentation Task2 study. The code uses the pinned CG-ICS `datasets/isic/class_id.csv` (SHA256 `312046a57ed9f563f331bb3c14517bb8d4a69c9e536a1a44bf720d5b7f263870`) to organize same-category reference selection into nevus, melanoma and seborrheic-keratosis groups. Those three groups are author-defined diagnostic strata, not three official patient-disjoint challenge folds. The selected source is public challenge **training** material; the project does not claim performance on the official challenge test set or patient-independent clinical generalization.

The challenge is named **2018**, while its summary paper `isic` was submitted to arXiv in **2019**. These dates are not a mismatch. The official challenge page recommends citing both the challenge report and the HAM10000 source paper; optional `ham10000` is supplied for that acknowledgement. Do not call the actual Task1 source a 10,015-image HAM10000 diagnosis benchmark.

**Input wording.** “Reference image + binary mask + query image, with no externally supplied class label or query mask” is accurate for the adapter boundary. It is not accurate to describe CG-ICS as language-free: the MLLM generates a concept phrase from reference pixels and the annotated region. Diagnostic/class metadata are used by the sampler/evaluator but are not passed as model text. Masks in the CG-ICS visual route become geometric box prompts; “mask-conditioned visual prompting” is safer than claiming direct mask-token prompting.
