\subsection{Coverage and Sampling}
The evaluation comprises 1,480 successful tasks and four reference-preprocessing failures, totaling 615,976 episodes. The standard cohorts contain 3,975 COCO and 13,750 LVIS distinct query targets on 3,820 and 9,051 images. The cohorts share 462 query images and are analyzed separately.

Common manifests preserve source class memberships, and predictions are evaluated against original-resolution ground truth. Sampling and aggregation follow the protocol defined in Section~\ref{sec:setup}. Empty LVIS source masks are excluded before sampling; all classes and folds remain. Confidence intervals are exploratory and unadjusted for multiple comparisons.

\subsection{Implementation Details}
The executed INSID3 implementation estimates its positional basis from an ImageNet-normalized all-zero image; the paper describes Gaussian noise. It retains original features for clustering and self-similarity and debiased features for cross-image matching. The main route uses bilinear restoration without CRF refinement. In CG-ICS, working images are size 512 before SAM~3's internal preprocessing, and nearest-neighbor restoration maps predictions to the original resolution. The direct-concatenation control uses the implemented query-side instance union. 

\subsection{Transfer Protocol}
Fresh core queries exclude images from the comparative evaluation using image hashes and canonical COCO identifiers across both datasets. The transfer scopes use the author-prepared merged SUIM pool and reorganized ISIC~2018 Task~1 training images. SUIM sampling excludes image--mask pairs with mismatched dimensions and retains all seven foreground classes. The protocol specifies 1,000 unique queries per transfer dataset. ISIC references use the supplied diagnostic strata within the public training pool; this differs from a patient-disjoint clinical evaluation or the official challenge test.

The fixed-pool scoring study generates candidates once per input, then evaluates alternative ranking rules on the same evidence. If the maximum combined score in the pool is below $10^{-6}$, all rules use the same visual fallback. Random search policies use fixed probabilities rather than probabilities selected from the gate's realized search rate. Staged always-search measures the extra initial probing cost.
